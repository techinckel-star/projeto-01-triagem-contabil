# Projeto 1 — Análise de Documentos Jurídicos com IA

## 1. Descrição

Este projeto utiliza inteligência artificial para analisar um contrato fictício de prestação de serviços, identificar possíveis riscos contratuais e sugerir melhorias nas cláusulas.

## 2. Objetivo

Desenvolver uma estrutura de automação jurídica capaz de auxiliar na leitura e análise de contratos, destacando pontos de atenção e organizando recomendações para revisão humana.
